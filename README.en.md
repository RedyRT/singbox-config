# singbox-config (English)

The main documentation is now in English: [README.md](README.md).

This skill targets **sing-box 1.14.4 stable** with two variants:

- **RealIP (default):** `references/templates/config-1.14.4-tun-realip.json`
- **FakeIP (optional):** `references/templates/config-1.14.4-tun-fakeip.json`

See the main README for usage, custom proxy modes, file layout, and validation commands.

Sources: [1.14.4 release](https://github.com/SagerNet/sing-box/releases/tag/v1.14.4), [official documentation](https://sing-box.sagernet.org/configuration/), and [migration guide](https://sing-box.sagernet.org/migration/).
